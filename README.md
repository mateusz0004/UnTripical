**# UnTripical - Under development**

UnTripical is a web application designed to help people find and share unique, "untripical" places. 
It allows users to create personalized Trip Plans and Trip Stops, while connecting travelers with
experienced Local Guides for authentic tours and experiences.

**## Features**

**### Places and Reviews**

* Search for places using filters like city, region, or type (typical or not typical)
* Suggest new places. New suggestions start as "waiting for approval"
* Local Guides review and approve new places to make them public
* Write reviews and give star ratings (1-5) for places and guides. Adding a review updates the place's or guide's average score.
  
**### Plan Your Trips**
* Create new Trip Plans with a name and date
* Include multiple Trip Stops in your plan and set their order
* The system calculates the total distance between all stops using the Google Maps API

**### Guides and Tours**

* Local Guides can create trips with details such as price, date, and description
* Filter tours by city, date, or event type
* Search guides by specialization and check their profiles for experience and average rating

**### SECURITY**
* User authentication and security are implemented using JWT (JSON Web Tokens).
